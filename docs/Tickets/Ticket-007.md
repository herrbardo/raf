# Descripción
Firmar el instalador de Windows. Conseguir un certificado de firma de código (o elegir Azure Trusted Signing) y cargar los secretos WINDOWS_CERTIFICATE_PFX y WINDOWS_CERTIFICATE_PASSWORD en el repo. Comprobar en un release que el instalador sale firmado y que SmartScreen no advierte.

Requiere del usuario: el certificado.
Plan: docs/plans/06-distribucion.md
